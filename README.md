# Retail Sales & Customer Analysis Dashboard (Power BI)

##  Project Overview
This Power BI dashboard provides an end-to-end analysis of retail sales performance and customer purchasing behavior. The interactive report helps analyze revenue streams, customer demographics, buying patterns, and sales trends to support data-driven business decisions.



## Key Features & Analysis
- **Sales Performance Tracking**: Visualizes revenue, total units sold, and profit margins across different product categories.
- **Customer Segmentation**: Analyzes customer purchasing patterns, demographics, and repeat purchase rates.
- **Trend & Seasonal Analysis**: Tracks monthly and quarterly sales performance to identify peak demand cycles.
- **Interactive Slicers & Filters**: Allows dynamic filtering by region, date range, product category, and customer segment.



##  Tools & Technologies
- **Power BI Desktop**: Data modeling, DAX measures, interactive visualizations, and dashboard layout.
- **Data Source**: Sales transaction logs and customer dataset (Excel/CSV).
